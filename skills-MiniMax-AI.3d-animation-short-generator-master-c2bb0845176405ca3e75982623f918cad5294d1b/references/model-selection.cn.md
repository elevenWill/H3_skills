# 视频模型选择与提示词改写

## 第 7 步：模型选择卡片 + 单镜头视频片段渲染

### 视频模型选择卡片（每次渲染片段前必须展示）

在任何片段渲染前，先展示视频模型选择卡。选择结果写入项目简报，并在用户后续更改前沿用到本项目所有片段。

视频模型说明：

- **H3（推荐默认）** — 在画面包装、运动图形、文字与 UI 清晰度、多模态上下文理解及性价比方面表现更强（2K 约为同级旗舰模型的 1/3，768P 为 1/2）。支持原生双声道音频。2K 单段上限约 15 秒。适合：有明显设计语言、带文字叠加、强调包装式转场、以及对话节奏为内容核心且音频本身需交付的风格化 3D 动画短片。
- **Seedance 2.0（高要求动画表现的兜底）** — 在电影级镜头语言、复杂镜头、弹性皮克斯式表演、紧张驱动动作方面更强。适合：追逐段、肢体喜剧节拍、卖点在“动画本身”而非包装的高潮镜头。
- **按镜头混合（高级）** — 允许用户在单行 `Shot Description` 的 `video_model: H3` 或 `video_model: Seedance2`。当项目既有重包装镜头也有重动作镜头时使用。未标记行默认用 H3。

### 分辨率选择卡（选定模型后）

模型锁定后，再展示分辨率选择卡：

- 768P（H3 首次出图推荐；性价比高）
- 2K（H3 默认质量；费用更高，画面更锐利）
- 1080p（Seedance 2.0 推荐）
- 720p（Seedance 2.0 草稿；最低成本）
- 与项目匹配 / 自定义分辨率

首个片段渲染前必须让用户确认分辨率。若后续希望某个重点镜头更高清，可在后期逐镜头调整。

### 单镜头片段渲染

对每一条已确认行，调用所选模型生成对应单独片段。每条片段必须严格使用文本分镜文档中对应部分（若该段已提取为独立节点则用独立节点，否则用正文段），对应角色卡与场景卡。

所有模型通用的单镜头规则：

- 将文本分镜文档作为叙事、构图、镜头运动、动作编排、秒级节奏、镜头编号的唯一来源。若已提取为独立节点，则优先读取该节点。若存在手绘分镜图，仅用于人类端姿态/轮廓预检，不得覆盖文本分镜。
- 角色身份以角色卡为准。
- 场景依据场景卡为准。
- 视频渲染前，删除所有分镜双重绑定标签（`[char:…]`、`[scene:…]`、`[shot:…]`、`[dur:…]`、`[hook:…]`），这些仅为分镜内部引用标记，不得出现在最终片段里。若有手绘分镜图，其自带的镜号、镜头图标、箭头与备注也必须在渲染时移除。
- 渲染片段应只保留干净的全彩皮克斯风 3D 动画画面。
- 不要出现分镜线稿、手绘纹理、标签、字幕（除非用户明确要求）、水印。
- 保持用户确认的画面尺寸 / 纵横比和分辨率选择卡中确认的分辨率。

### 模型化提示词改写

文本分镜文档（或对应镜头已提取独立节点）会同时驱动两个模型，但分镜附近的提示前缀不同：

- **H3 提示词前缀**（默认）：强化包装关键词、设计语言、运动清晰度、必要时的文字与 UI 存在提示，以及双声道音频意图。H3 对指令遵循强，秒级指令可接近原样发送。补充：`Pixar-inspired 3D cartoon rendering, C4D + Octane look, stylized Q-version proportions, warm SSS skin, designed-with-detail hair, strong character design language, clean motion, on-brand color palette`。
- **Seedance 2.0 提示词前缀**（性能兜底）：强化电影镜头语言、弹性挤压拉伸、起势与随动、光照戏剧性、镜头选择。补充：`cinematic Pixar-quality 3D animation, elastic squash-and-stretch performance, Disney-style anticipation and overshoot, dramatic key lighting, lens-specific depth of field`。

当用户选择 `per-shot mixed` 时，按行 `video_model` 字段选择对应前缀。

# 生成失败与漂移兜底策略

### 按模型的失败兜底

H3 失败/漂移时的重试路径：

1. 第一次重试：使用表格中精确 `Reference Anchors` 文本加码，重新生成同一片段。
2. 第二次重试：将镜头缩短到 ≤6 秒，并在第 5 步把裁剪掉的秒数拆成相邻新行；重新执行第 5.5 自检后再渲染。
3. 第三次重试：把失败镜头切到 Seedance 2.0（这就是混合模式的意义——性能兜底只需一键切，不改整体架构）。
4. 同一镜头三次失败后：暂停并通过选择卡征询用户：
   - 仅把当前镜头切到 Seedance 2.0
   - 放宽要求（去掉一个道具、简化动作、减弱钩子）
   - 跳过该镜头，并写入 `placeholder: missing clip` 给下游评审
   - 手动提供参考视频用于绑定，而不是重新生成

Seedance 2.0 失败兜底（当用户明确选择全局 Seedance，或 H3 已失败三次后）：

1. 第一次重试：用增强后的提示词重生成，并引用 `Reference Anchors` 区块。
2. 第二次重试：去掉参考图，用纯文本生成。
3. 第三次重试：将镜头缩短到 ≤6 秒，并把省掉秒数拆成新行。
4. 三次失败后：询问用户——切到 H3、放宽要求、跳过镜头、或提供参考视频。

### 全部片段渲染完成后

按镜号顺序把渲染片段放到画布，分组为 `<title> shot clips`（不再硬编码单一模型名），并展示用户选择卡：

- 通过片段并合成完整版（推荐）
- 重新渲染选定片段（同模型或切模型）
- 修复角色错位
- 修复场景错位
- 加强分镜清理
- 修复跨片空间锚点漂移

若渲染片段偏离已确认的 `Reference Anchors`（例如门框落在错误侧、角色从错误边缘离场、明暗反转），用包含精确 `Reference Anchors` 的增强提示重渲染。若仍漂移，则在混合路径下把该镜头切到另一模型；严禁在合成中偷偷混用已修正与未修正片段。

## 分镜可视化兜底

### 分镜图失败兜底（仅可视化模式）

若手绘分镜图无法达标（例如布局塌陷、标签不可读、分格合并、角色不一致），在询问用户前按以下顺序升级：

1. **第一次重试**：重生成同一镜头分镜图，使用更严格提示，明确提到四象限布局、`[char:…] [scene:…] [shot:…]` 标签和每格内容规则。
2. **第二次重试**：去掉右下角音频/锚点象限文字（保留空格并放一个小 `♪` 标记），降低文字负荷；通常可保留视觉节拍同时解决标签不可读问题。
3. **第三次重试**：减少一格面板（例如 6 格降到 5 格，通过合并动作最少的两秒）并把摄像头图标简化为单箭头。
4. **同一镜头连续三次失败后**：暂停并通过选择卡询问用户：
   - 将该失败镜头切到块面分镜（灰块代替姿态，取消铅笔线）
   - 仅该镜头取消手绘分镜，改用文本分镜文档
   - 把该失败镜头在第 5 步拆成两个更短镜头并重跑第 5.5 步
   - 人工提交参考图替代生成

默认文本模式下无需整套可视化兜底——文本分镜仅在模型无法产出连贯结构化文本时失败，此时应回到第 5 步重写表格行。

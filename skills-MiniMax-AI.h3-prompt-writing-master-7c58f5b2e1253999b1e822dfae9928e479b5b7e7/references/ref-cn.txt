# 完整参考模式改写输出格式指南

本指南说明在 full-reference 模式下，改写输出如何组织与编写。

所有六个改写部分都应使用英文写成。仅对 `<d>` 内的对白和歌词，以及场景中可见文本保留原始语言。

## 描述要求

将 `detailed_description` 写得尽可能详细和明确。对每个镜头，需清楚建立当前构图、主体外观与位置、环境与光线、动作与状态变化、镜头运动、当前声音，以及参考内容实际出现或生效的时间点。避免把描述压缩成剧情梗概或仅仅列举参考关系。

> 镜头、镜头运动、发言者、对白和普通音效的基础格式与《视频提示词编写指南（T2VA / I2VA / FL2VA / L2VA）》保持一致；本指南聚焦于参考标签、分析段落以及该模式的格式差异。

## 1. 整体结构

完整改写输出按以下顺序包含六个部分：

| 部分 | 目的 |
| --- | --- |
| `subject_definitions` | 定义引用内容及其参考标签 |
| `summary` | 概括任务类型、目标视频与主要参考关系 |
| `retention_analysis` | 说明被引用内容如何被保留、迁移或复用 |
| `detailed_description` | 按播放顺序描述画面、动作、镜头、音效和对白 |
| `overall_soundscape` | 总结环境声与物理音效 |
| `non_diegetic_music` | 描述仅观众可闻的背景音乐 |

## 2. 参考标签与定义（`subject_definitions`）

完整参考改写使用四类标签标识引用内容来源与作用：

| 标签 | 含义 |
| --- | --- |
| `<Subject N>` | 从参考素材中抽象出的可复用可见内容，可在目标视频中被复用或修改 |
| `<Picture N>` | 作为具体目标帧或分镜锚点使用的参考图 |
| `<Video N>` | 提供编辑来源、续写起点或完整时间结构的参考视频 |
| `<Audio N>` | 被复制或引用的音频信号 |

> 一旦某段内容被赋予参考标签，`subject_definitions`、`summary`、`retention_analysis`、`detailed_description` 及音频段落中其含义应保持一致。

`subject_definitions` 需要逐条定义每个后续需要单独跟踪的引用内容，例如人物、环境、源视频结构、音轨等。每个条目说明该标签所代表内容、引用角色和主要保持特征；当需要明确来源素材时应写明对应素材。若 `<Picture N>` 或 `<Video N>` 仅用于指明另一个被跟踪项的来源，并不单独参与后续分析，则在该项定义中内嵌引用即可，不要再单独建行。`retention_analysis` 用于记录每个被引用项出现的位置及其是完整保留、部分保留、迁移或复用。

### 2.1 `<Subject N>`

`<Subject N>` 用于可复用可见内容，包括：

- 人、动物、物体
- 场景、背景或环境
- 服饰、道具、界面、视觉特效
- 风格、动作、表情或姿态

它表示会在目标视频里实际出现的内容单元，而非源文件本身。一个 subject 可由多个参考资产定义；一个参考资产也可提供多个 subject。

```text
<Subject 1> is the young woman in <Picture 1>, with long dark hair, a blue cardigan, and a thin silver necklace.
```

当同一 subject 来自多个素材时，合并来源并说明每个资产提供了什么：

```text
<Subject 1> is the woman whose appearance comes from <Picture 1> and whose walking motion comes from <Video 1>.
```

### 2.2 `<Picture N>`

当参考图本身作为某个镜头的首帧、关键帧、末帧、编辑关键帧或构图锚点时，使用独立的 `<Picture N>`：

```text
<Picture 2> is the first frame of [Shot 1], showing a woman seated beside a café window.
```

如果图仅用于定义角色、场景、服装或风格，不要单独创建 picture 条目；将其作为来源写进对应的 `<Subject N>`。

当图像作为分镜或分镜规划参考时，说明它对应哪些镜头及提供的规划信息：

```text
<Picture 3> is a storyboard reference for [Shot 1] and [Shot 2], defining their viewpoint, subject placement, and shot order.
```

### 2.3 `<Video N>`

`<Video N>` 用于全视频关系，例如：

- 剪辑一个原始视频
- 从原始视频继续
- 参考原视频的镜头运动、剪辑节奏、时间结构

```text
<Video 1> is the source video for the target video edit.
```

如果从参考视频中复用了人物、物体、场景、动作或特效作为可见内容，这仍归入 `<Subject N>`。`<Video N>` 仅标识素材或结构来源，不替代 subject 标签。

### 2.4 `<Audio N>`

`<Audio N>` 表示独立音频素材或来自参考视频中的启用同步音轨。常见用途包括：

- 复制全部或部分音频信号
- 引用背景音乐风格
- 引用说话人音色与表达
- 使用原始音频中的对白、歌词或音效
- 引用节拍、节奏或音频连续性

当 `<Audio N>` 对应目标说话人时，复用该说话者在目标视频中的全局 ID：若与已定义 subject 映射则写 `<Subject N> (Sx)`，否则写稳定的声色描述后接 `(Sx)`。ID 按目标视频的全局发言顺序产生，不在音频定义中单独重排。详见第 5.4 节发言编号规则。

```text
<Audio 1> is the voice-timbre reference for <Subject 1> (S1).
```

单个音频资产承担多个角色时，用一句自然语言描述全部角色，不另建子节。

### 2.5 同一参考视频的视觉与音频轨道

`<Video N>` 与 `<Audio N>` 独立编号。每个索引仅表示该类别内的顺序，不表示跨类别配对关系。同一参考视频可分别对应 `<Video 1>` 与 `<Audio 2>`；不同索引不妨碍它们来自同一素材。

普通参考视频不因为包含声音就会自动生成 `<Audio N>`。

`<Audio N>` 的定义主要说明音频角色，不必必须写明对应的 `<Video N>`。只有在有歧义时才补充来源，例如：

```text
<Video 1> is the source video for the target video edit.
<Audio 2> is the synchronized audio track of <Video 1> and is reused in the target video.
```

## 3. `summary`

该段用一段简短英文总结目标视频及其参考关系，以中括号任务类型前缀开头：

```text
[reference generation] ...
[video editing + reference generation + audio reuse] ...
```

按实际参考角色选择任务类型：

| 任务类型 | 适用场景 |
| --- | --- |
| `keyframe completion` | 图像作为目标视频首帧、关键帧、末帧、编辑关键帧或其他具体帧锚点 |
| `reference generation` | 图像、视频或音频提供角色、场景、风格、动作、镜头运动、分镜等生成指导，但不作为具体帧或被直接编辑/续写的源视频 |
| `video editing` | 直接修改已有源视频；在图像或关键帧之间生成不算此类型 |
| `video continuation` | 新内容从已有源视频延续、扩展、恢复或过渡 |
| `audio reuse` | 直接复用同一音频信号 |
| `audio reference` | 未直接复制音频，仅参考其风格、音色、对白/歌词内容、音效质感、节拍或连续性 |

当任务同时满足多个关系时，用 ` + ` 组合并避免重复，例如续写并使用末帧图像写作 `[video continuation + keyframe completion]`。编辑源视频同时保留原音时可写 `[video editing + audio reuse]`。

视频或音频的存在并不会自动生成对应任务类型。若参考视频只提供镜头运动、剪辑或节奏，通常应归入 `reference generation`。只有源视频被直接编辑或继续时才使用 `video editing`/`video continuation`。

编辑源视频时，若原音仍可听则一并使用 `audio reuse`。若不直接复制音轨信号而继续播放同一轨道特征，则使用 `audio reference`。

`summary` 使用已定义的 `<Subject N>`、`<Picture N>`、`<Video N>` 与 `<Audio N>` 来描述主体、镜头流程和素材关系，避免引入新标签。

对于视频编辑任务，`summary` 在任务前缀后应以如下开头：

```text
The target video is an edited version of <Video 1>.
```

## 4. `retention_analysis`

该段说明每个引用内容如何被保留、迁移、复制或仅被参考。每个标签一行，沿用 `subject_definitions` 的含义。

### 4.1 可见内容

`<Subject N>`、`<Picture N>`、`<Video N>`使用以下关系标记。标记值是固定英文，不要改写：

| 关系标记 | 含义 |
| --- | --- |
| `fully_preserved` | 被定义角色被完整保留 |
| `partially_preserved` | 仍在使用，但部分特征被修改或仅部分保留 |
| `attribute_transfer` | 参考特征转移到不同的可识别目标主体 |
| `weak_reference` | 仅保留了风格、类别、构图或氛围的广义相似 |

Subject 示例：

```text
<Subject 1> (appears in [Shot 1], [Shot 3]): fully_preserved - ...
```

Picture 示例：

```text
<Picture 2> ([Shot 1] first frame): fully_preserved - ...
```

Video 结构示例：

```text
<Video 1> (cut and pacing structure): weak_reference - ...
```

### 4.2 音频

`<Audio N>` 使用以下关系标记：

| 关系标记 | 含义 |
| --- | --- |
| `fully_copy` | 完整源音轨作为目标视频最终音轨完整复用 |
| `partially_copy` | 只复制了时间轴部分或选定图层，或复制后又增删/替换了其他声音 |
| `reference` | 不直接复制，且仅参考音色、节奏、音乐风格、对白内容或音色质感 |
| `weak_reference` | 仅保留了类别、氛围等广义相似度 |

```text
<Audio 1>: fully_copy - <Audio 1> is reused 1:1 as the target video's complete final audio track.
```

```text
<Audio 2>: reference - the target speaker follows <Audio 2>'s voice timbre and measured delivery without copying the original signal.
```

关系标记必须仅在 `subject_definitions` 中定义的对应角色范围内使用。不要因为新增动作、背景或情节而把它当作参考丢失。

## 5. `detailed_description`

这是完整参考改写的主体，按目标视频时间顺序逐镜头描述视觉、动作、音频与对白，并在适当位置插入参考标签。

### 5.1 基础格式

基础格式沿用《视频提示词编写指南（T2VA / I2VA / FL2VA / L2VA）》：

- 正文使用英文。对白、歌词和可见文本保留原语言。
- `[Shot 1]` 标记开场，不带时间戳；后续镜头用 `[Shot N] At MM:SS.mmm, ...` 标记切点。
- 摄影机运动以当前镜头内的自然英文表达给出，必要时再补充类型、幅度、速度。
- 说话源使用稳定 `(S1)`、`(S2)` 等；对白歌词写在 `<d>[Language] ...</d>`。
- 对跨镜头持续对白、结尾截断对白、跨镜音频连续性分别使用 `<scenetrans>`、`<cutoff>` 并写明音频持续。

完整规则与示例请参考《视频提示词编写指南（T2VA / I2VA / FL2VA / L2VA）》中关于镜头词表、群组对话、配音、跨切对白与可见文本的部分。

### 5.2 完整参考模式差异

| 维度 | T2VA | Full-reference mode |
| --- | --- | --- |
| 主体字段 | `integrated_multimodal_description` | `detailed_description` |
| 风格开场 | 在 `[Shot 1]` 后写 | 在 `[Shot 1]` 前用一到两句英文独立说明 |
| 参考信息 | 不使用完整参考标签 | 在首次出现及适用阶段插入 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>` |
| 音频关系 | 描述目标视频自身声音 | 在对应镜头或音频阶段标注 `<Audio N>` 并说明复制或参考关系 |

开场示例：

```text
The target video is in a cinematic, literary music-video style with soft lighting and a slightly desaturated color palette.
[Shot 1] The scene opens in a crowded urban street...
[Shot 2] At 00:09.000, the shot cuts to an extreme close-up...
```

生成类任务中，`detailed_description` 通常为 350–500 英文词。对白密集时优先保证完整口述时间线而非机械达到字数。编辑类描述可随源视频复杂度增长，不要求固定字数；单镜头并不天然允许缩到很短，需按信息量在多镜头中分配细节。

### 5.3 在镜头中使用参考标签

当关键 `<Subject N>` 首次清晰出现时，说明其对应特征、画面中位置与当前动作，并与镜头的实际可见内容保持一致。后续镜头重复该标签时不再重定义含义。

锚点句示例：

```text
the shot begins from <Picture 1>
the shot's keyframe corresponds to <Picture 2>
the shot ends on <Picture 3>
```

编辑或续写原视频时，在源状态、结构或续写关系适用处自然引入 `<Video N>`；在音频关系激活处在对应镜头/语义阶段使用 `<Audio N>`。

### 5.4 发言者、音频来源与对白

发言者 ID 与 `<d>` 的基本规则沿用 T2VA。当被引用角色进行实际发言时，同时保留可见参考标签和 speaker ID：

```text
<Subject 2> (S1) turns toward the woman and says, <d>[English] Last summer, I went to my grandfather's house. He talked about you.</d>
```

`<Subject N>` 表示被引用主体；`(Sx)` 表示真实发言者。当角色发言时写作 `<Subject N> (Sx)`。同一角色离屏发言时保持同形并标为 `off-screen`。当发言者不对应任何定义 subject 时，用稳定语音描述 + `(Sx)`。

当口头内容只是直接复用 BGM 或完整原声轨中的 cue，而画面中无真实独立人物/角色/旁白/声源产生时，用 `<Audio N>` 标明声源，不要额外伪造 `(Sx)`。若存在真实人物、角色、旁白等独立发声源，则应给该源分配并复用 `(Sx)`：

```text
When <Audio 1> reaches the phrase <d>[English] I'm lonely lonely lonely lonely lonely I'm lonely</d>, <Subject 1> performs the corresponding hand gesture without becoming a separate speaker source.
```

当直接复用参考音频中的对白、旁白或歌词，或输入明确要求复述时，必须在 `<d>` 内保留完整原词与原语言。不可懂片段写作 `[unclear]`，禁止猜测或改写。标点标准化为基本书写符号（`, . ? !` 等），去掉重复波浪线、表情符号、项目符号和重复装饰性标点。完整句式、问句、感叹句在 `</d>` 前分别用 `.`, `?`, `!` 结束。

仅参考音色、节奏、情绪或演绎方式时，不要将原对话直接带入目标视频。

按目标视频实际发声事件顺序一次性分配 `(Sx)`，并在后续每次发声保持复用；在 `subject_definitions` 中绑定到目标说话者的 `<Audio N>` 也沿用同 `(Sx)`，但不能独立再分配新编号。`retention_analysis` 中不要写 `(Sx)`。

如果某条语音提示只存在于直接复用的 BGM 或完整音轨中，应使用 `<Audio N>`；由具体人物、角色、旁白等独立发声源产生的语音使用 `(Sx)`。

## 6. `overall_soundscape` 与 `non_diegetic_music`

这两个声音分类定义与《视频提示词编写指南（T2VA / I2VA / FL2VA / L2VA）》保持一致。

`overall_soundscape` 总结全片环境和物理音效。对白、唱歌及与特定镜头同步的音效仍保留在 `detailed_description`。

```text
overall_soundscape: Quiet indoor room tone and a low ventilation hum continue throughout the video.
```

`non_diegetic_music` 描述角色听不见、仅观众可听的背景音乐；要写明编制、节奏和动态变化。

```text
non_diegetic_music: A restrained solo-piano score at a slow tempo, with sustained low cello underneath and no swell.
```

若使用参考音频，应分别在对应层次说明复用/参考关系：环境与音效放在 `overall_soundscape`，观众可听配乐放在 `non_diegetic_music`；若同一音频同时提供两类内容，则在各自段落里分别说明。

```text
overall_soundscape: The copied ambience layer from <Audio 1> continues throughout the target video.
non_diegetic_music: <Audio 2> is directly reused as the complete audience-only score.
```

完整对白与歌词只写在 `detailed_description` 的 `<d>` 内，不要在这两段重复。

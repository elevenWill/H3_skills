# H3 确认图模板

## 核心规则

为合作模式游戏主菜单生成一张精修的 16:9 横版确认图。图像由两套独立系统组成：
• UI 框架（固定）
• 视觉风格（动态）

UI 框架定义了布局、构图、信息层级、交互逻辑、阅读流、菜单结构与可读性，这些元素必须保持不变。
`{visual_style}` 仅控制艺术化外观，包括渲染媒介、材质、色彩语言、光照氛围、环境风格、角色设计、服装语言、UI 材质、图标语言、字体外观、装饰元素及整体氛围。
切换 `{visual_style}` 应表现为给同一套专业游戏菜单换一套视觉方向，而不是重做界面本体。
若默认描述与 `{visual_style}` 冲突，以 `{visual_style}` 优先，同时保留 UI 框架。

---

## 设计目标

制作一个 16:9 横版的高品质商用主机游戏主菜单示意图。图像需要兼具商业级游戏宣传图的品质与专业游戏 UI 的清晰度，角色与界面应自然融合，具备明确的视觉层级、极高可读性、干净构图与清晰的交互焦点。

---

## 整体风格

遵循用户选择的视觉风格：`{visual_style}`。
所选风格会控制渲染媒介、插画风格、材质、色盘语言、环境、角色外观、服装设计、UI 外观、图标语言、字体处理、装饰元素和整体氛围。
所有视觉元素必须使用同一套统一艺术语言。
不要在同一张图里混搭不兼容风格。
无论风格如何，UI 框架、布局、层级、构图与交互逻辑都必须保持一致。

---

## 色盘

完整色彩体系需从 `{visual_style}` 派生：

- `{main_background_color}` 作为主背景色。
- `{ui_body_color}` 作为主 UI 色。
- `{text_color}` 作为主文字色。
- `{functional_accent_color}` 作为交互高亮色。
- 红色仅用于警示、危险或退出行为。
- 总体主色不超过五色。
- 所有按钮、玩家卡片、图标、边框、高亮、装饰、字体和视觉特效都必须使用同一套色彩体系。
- 不要添加与选中色盘无关的颜色。

---

## 构图

使用固定 16:9 横版布局。
- 将 `{character_count}` 个可玩角色放置在中央作为主要主体。
- UI 环绕角色且不挡住角色。
- 左上角放置玩家信息卡。
- 右侧竖向放置主菜单。
- 底部放置装饰横向条，按 `{visual_style}` 自然延展（如横幅、警戒条、木板、石板、能量条、卷轴等）。
- 保留清晰的 Z 字阅读路径：
  `玩家卡片 → 角色 → 菜单 → Continue 按钮`
- Continue 按钮必须始终是视觉主焦点。
- 保持充足留白与优秀可读性。

---

## 背景

从 `{visual_style}` 自然生成背景。
背景应服务界面，而非与其竞争。
在所有重要 UI 元素后方保留足够干净留白。
仅在 `{visual_style}` 合理位置使用细微纹理、环境细节与装饰花纹。
避免过多视觉噪声、过密装饰、重度污迹、划痕、飞溅油漆或分散注意力的纹理。
整体背景应当显得精致、精品、现代，且适合作为商业游戏菜单背景。

---

## 角色风格

所有角色必须严格遵循 `{visual_style}`。
所选风格决定：
- 渲染媒介
- 人体比例
- 脸部风格化
- 服装语言
- 材质处理
- 光照反应
- 动画风格
- 角色整体质感

身份锚点和姿态保持不变。面部渲染、眼睛设计、鼻型简化、嘴型、肤色处理、表情风格、头部比例必须完全按 `{visual_style}` 重设。
默认角色风格不能覆盖 `{visual_style}`。

## 光照

光照按 `{visual_style}` 执行，但要保持清晰可读：
- 主要顶光
- 次级填充光
- 柔和环境反射
- 接触阴影
- 柔和边缘光
- 适度全局光照
人物面部应清楚可见，角色应自然融入环境且与背景有清晰分离。

---

## 游戏 UI

创建一个专业的商用主机游戏主菜单。
菜单结构、交互层级、间距、构图、阅读流程和信息架构保持固定。
`{visual_style}` 只影响界面艺术外观。
所选风格可改变：
- UI 材质
- 表面纹理
- 边框处理
- 拐角形状
- 装饰图样
- 色彩渲染
- 光照处理
- 图标语言
- 字体样式
- 交互效果

不能改变：
- 菜单层级
- 按钮顺序
- 按钮位置
- 玩家卡放置
- 构图
- 交互逻辑
- 信息架构
- 可读性

整个界面应像一个一体化的专业游戏 UI 系统，而不是拼接来的独立元素。

---

## UI 视觉语言

整体 UI 外观按 `{visual_style}` 完整派生。
所选风格决定：
- 按钮材质
- 边框语言
- 面板材质
- 装饰细节
- 边缘处理
- 视觉权重
- 高亮样式
- 交互反馈
- 阴影处理
- 纹理语言

可选材质示例：
- 木、石、纸、皮革、布、玻璃、水晶、全息、霓虹、金属、陶瓷、雕刻面、喷涂面、魔法能量、像素块、宣纸、水墨笔、漫画图形 或任何自然符合 `{visual_style}` 的材质。

所有 UI 元素共享同一材质语言与艺术风格。

---

## 按钮布局规则

将所有菜单按钮垂直排在右侧。
保持稳定一致的垂直节奏。
每个按钮使用同一家族样式。
按钮宽度按文字长度自动适配。
所有按钮标题单行展示，不自动换行，不可上下叠字。
文字居中对齐。
内边距一致，按钮间距等距。
避免视觉杂乱。

---

## Continue 按钮

Continue 按钮始终是视觉主焦点。
按 `{visual_style}` 合理的方式加强强调，例如：
- 更大尺寸
- 更高对比
- 更亮颜色
- 独特材质
- 独特边框
- 合理光照
- Glow/辉光
- 雕刻感
- 魔法能量感
- 全息效果
- 浮雕边框
- 动态视觉提示

不要强加与风格冲突的发光或霓虹效果。
Continue 按钮要能一眼吸引注意。

---

## 新游戏按钮

位于 Continue 上方，使用标准次级样式。
图标、材质与整体视觉语言保持与 `{visual_style}` 一致。
可选添加一个风格合适的小图标。
标题保持单行。

---

## 设置按钮

使用标准次级外观，保持按钮比例、间距与层级稳定。
图标沿用 `{visual_style}` 的样式。

---

## 退出按钮

使用标准次级外观。
红色仅作危险提示使用，并保持为点缀色。
可选添加一个风格匹配的退出图标。

---

## 玩家卡

给 `{character_count}` 名玩家创建左上角角色信息系统。
外观按 `{visual_style}` 控制。
卡片材质、边框、圆角、纹理、阴影、装饰和图标全部从所选风格衍生。
每张卡需包含：
- 玩家标签
- 玩家昵称
- READY 状态

玩家名称：

`PLAYER 1`
`{player1_name}`
`PLAYER 2`
`{player2_name}`

READY 永远使用功能高亮色。
卡片必须高可读且与整体界面联动一致。

---

## 图标系统

所有图标从 `{visual_style}` 推导，整套界面仅使用同一图标族：
- 极简线框
- 实心填充
- 几何
- 漫画
- 像素
- 雕刻
- 雕版
- 油漆
- 笔刷
- 绘符
- 铭文
- 全息
- 水晶
- 剪纸
- 折纸
- 压花
- 低多边
- 扁平
- 风格化 3D

所有图标统一：
- 同一艺术风格
- 同一材质语言
- 同一透视
- 同一光照
- 同一笔画语言
- 同一色彩层级

图标保持简单、易识别、功能导向。
每个界面块最多一行图标，不换行、不竖向堆叠。
图标应支撑界面而非抢戏。

---

## 字体

字体层级固定，外观按 `{visual_style}` 控制。
所选风格决定：
- 字体家族
- 装饰处理
- 纹理
- 材质
- 描边
- 光照
- 阴影
- 磨损样式

保持：
- 高可读性
- 强视觉层级
- 菜单按钮单行
- 间距一致
- 对比度高

按钮宽度始终随文本长度自适配。
按钮标题禁止换行。

---

## 游戏标题

展示游戏标题：`{game_title}`
标题应成为菜单第一品牌识别点，材质、装饰、字体与渲染全部按 `{visual_style}`。
不要仿制现有商业游戏 logo。
创建受所选风格启发的原创标题处理，保持高可读性。
避免随机符号与无意义文字。

---

## 交互状态

界面需表达“正在运行中的游戏菜单”。
按钮可出现与 `{visual_style}` 相匹配的交互反馈，示例：
- hover
- 按下态
- 魔法辉光
- 能量脉冲
- 全息高亮
- 雕刻光
- 墨迹扩散
- 笔锋晕散
- 金属反射
- 纸张压花
- 动态边框
- 像素闪烁

只使用与当前风格一致的交互效果，不要强塞不匹配的现代 UI 特效。

---

## 渲染

生成高精度 AAA 级商用游戏菜单美术图。
角色、环境、UI、字体、图标、装饰元素应像一个统一产物，具备以下特征：
- 高清渲染质感
- 强层级
- 专业商业级展示
- 高可读性
- 构图平衡
- 干净收尾

---

## 负向约束

- 不要使用分屏
- 不允许角色重复
- 不允许身份互换
- 不可丢失身份锚点；未明确要求不要出现写实人脸
- 禁止将真实照片人脸贴到风格化身体上或风格错位
- 不允许发型变化
- UI 不可不可读
- 按钮不可变形
- 接口不可重叠
- 不要出现随机文字
- 不要出现随机符号
- 禁止水印
- 禁止抄袭游戏 logo
- 禁止出现品牌化界面
- 图标风格必须一致
- 避免混用 UI 材质
- 避免过度装饰
- 背景不得盖过主体
- 不要视觉杂乱
- 不可出现布局崩坏
- 可读性不可下降

---

## 介质锁定

渲染为“游戏关键画面 + 专业主机主菜单”混合级效果。
界面结构保持固定，只有艺术外观随 `{visual_style}` 变化。
